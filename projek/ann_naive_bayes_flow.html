Tahap Training Model

🧠 Artificial Neural Network

Arsitektur:

  • Input Layer: Fitur proyek
  • Hidden Layers: 2-3 layers dengan ReLU
  • Output Layer: Probabilitas risiko

Training:

  • Backpropagation algorithm
  • Adam optimizer
  • Cross-entropy loss
  • Dropout regularization

📊 Naive Bayes Classifier

Jenis Model:

  • Gaussian NB: Fitur numerik
  • Multinomial NB: Fitur kategorical
  • Bernoulli NB: Fitur binary

Training:

  • Maximum likelihood estimation
  • Laplace smoothing
  • Prior probability calculation
  • Conditional probability modeling
